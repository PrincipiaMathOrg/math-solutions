# MathDB formalizations

Lean 4 formalizations of 186 problems from the MathDB open-problem collection, produced by
Principia's formalization campaign and checked on the authors' machine.

**143 of the 186 are fully verified and are the ones tabulated below. The other 43 are not**,
and they are listed separately in [PARTIAL.md](PARTIAL.md) with what each one proves and what
it still assumes. Nothing in this file is about those 43; do not read a module's presence in
this directory as a verification of its problem.

## What "verified" means here, and what it does not

Each module below builds against the pinned toolchain and Mathlib revision in this
directory, contains no `sorry` and no local `axiom`, and every declaration's
`#print axioms` footprint is inside `[propext, Classical.choice, Quot.sound]` -- measured by
a per-module gate run, not asserted.

**The Comparator has been run on one of these problems: #343324, which passed.** It has a
`Challenge343324.lean` / `Solution343324.lean` contract, a `comparator/343324.json` config and
a `mathdb-comparator` workflow run on this repository, and the Principia project records the
verdict. The other 142 problems have **no contract**, so for them the site's formalization
stage link is a pointer to source a reader can rebuild, not a comparator verdict. What a pass
does and does not establish -- in particular that it does *not* certify faithfulness to the
MathDB problem text -- is set out in [VERIFICATION.md](VERIFICATION.md).

**A row is not a claim that the source conjecture is settled.** Many of these results are
*refutations* -- an explicit counterexample to the stated conjecture -- and others formalize a
corrected or narrowed statement where the problem as written turned out to be false. The
statement column says which; the module's own header says it at length, including what each
module still owes.

## Building

```
cd mathdb
lake exe cache get
lake build Principia
```

`Principia.lean` imports all 229 modules in this directory: 204 under `Principia/MathDB/`
(including `Statements/P343324.lean`, the proof-free statement layer of the one Comparator
contract) and 24 shared results under `Principia/Common/`.

Those 204 modules carry **187** distinct problem numbers: the 143 verified below, the 43 in
[PARTIAL.md](PARTIAL.md), and `Problem331409`, which is here only because a listed module
imports it -- its own Principia project has an owner, so it gets no row of its own.
